# Контекст проекта: Leaf & Cup (pet-проект интернет-магазина)

## Кто пользователь и зачем это нужно

Пользователь — начинающий full-stack разработчик (резюме: React 18, TypeScript, Vite, Node.js, Express, REST API, JWT, PostgreSQL/MongoDB, Prisma, WebSockets; есть опыт с AI/LLM — Whisper STT, TTS). B.Sc. Informatik, живёт/работает в немецкоязычном регионе (DE B2, Anerkennung диплома в Германии), сейчас в поиске работы.

**Цель проекта**: pet-проект для портфолио, который закрывает пробелы в резюме и показывает уровень выше junior. Будет одним из проектов на отдельном сайте-визитке пользователя.

**Почему e-commerce**: осознанно выбран как проект, который естественно требует БД+ORM, аутентификацию и роли, корзину+checkout+оплату, админ-панель, Docker+CI/CD (GitHub Actions — **сейчас нет в резюме, главный пробел, который должен закрыть проект**), e2e-тесты (Playwright — тоже пробел). Договорились НЕ клонировать готовый шаблон 1:1, а использовать чужие макеты только как референс, чтобы на собеседовании можно было объяснить архитектурные решения.

## Бренд и ниша

- **Название**: **Leaf & Cup**
- **Ниша**: чайный магазин — сорта чая, чашки, заварники, наборы. Пользователь сам любитель чая.
- **Дизайн-референс**: https://www.figma.com/community/file/1255525288557123779/e-commerce-free-ui-kit — макет ещё будет дорабатываться, не считать финальным.
- **Стиль**: минимализм в духе Aesop/COS/Vercel/Linear — крупная чистая типографика (Geist/Inter), сдержанная палитра (чёрный/белый/тёплый терракотовый акцент), БЕЗ ярких градиентов и pill-кнопок, много whitespace.
- **Лого**: `public/images/logo.png` (полный лендинг-вариант с фразой "Погрузитесь в мир вкуса и аромата. Мы собрали для вас лучшие сорта чая, уютные чашки и заварники, чтобы каждое домашнее чаепитие приносило радость." использовать как маркетинговый текст на сайте, НЕ в title/meta), `src/app/icon.png` — иконка/favicon (прозрачный PNG). Raw-исходники (`logo.jpg`, `favicon.jpg`) лежат рядом в `public/images/` на случай пересборки.
- **Title/description сайта** (закреплено, не менять без запроса): title `Leaf & Cup — интернет-магазин чая`, description — текст про "Погрузитесь в мир вкуса и аромата...".

## Технический стек

- Frontend: Next.js 16 (App Router) + TypeScript + Tailwind v4 + shadcn/ui (preset **Nova** — Geist шрифт, Lucide иконки, base radix)
- Backend: **Next.js API routes** (не отдельный Express) — решено ради единого репозитория/деплоя
- ORM/DB: Prisma + PostgreSQL (ещё не подключены)
- Оплата: Stripe (тестовый режим, не подключено)
- Auth: JWT, роли покупатель/админ — **следующий шаг, см. ниже**
- Инфраструктура: Docker + docker-compose, GitHub Actions CI — ключевая цель проекта, не забыть
- Тесты: Playwright e2e по ключевому флоу (просмотр товара → корзина → checkout)
- MCP: подключён `shadcn` MCP-сервер (`.mcp.json`) — даёт агенту доступ к настоящим shadcn-компонентам вместо вёрстки CSS "на глаз"
